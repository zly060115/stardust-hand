# 二次开发说明

整个作品只有一个文件：`index.html`（约 1200 行，HTML + CSS + JS 全在里面）。
没有构建步骤、没有 npm 依赖，改完直接刷新浏览器就生效。

> 下表里的行号写于某个版本，代码一改就会漂。定位时**优先用函数名搜索**
> （比如搜 `updateHands`），行号只是大致参考。

## 二、最常调的参数

**手感（`updateHands`，约 453 行）**
```js
h.strength = 2.05 - 2.85 * h.spread;  // 握拳→强吸引；张开→负值=排斥
h.swirl    = 0.05 + 1.05 * h.spread;  // 张手时的旋转强度
```
- 想更"抓得住"粒子：把 `2.05` 调大（如 2.6）
- 想张开手时排斥更猛：把 `2.85` 调大（如 3.8）
- 想让星云转得更疯：`swirl` 第二个数调大（如 1.8）

**粒子密度（`initParticles`，约 323 行）**
```js
NEBULA = Math.round(Math.min(2600, Math.max(1200, area / 760)));
```
数字越大越密，卡就往下调（`2600` → `1600`）。

**拖尾长短（`draw`，约 559 行）**
```js
ctx.fillStyle = 'rgba(3,4,12,0.165)';
```
- `0.165` 调小（如 0.08）→ 拖尾更长、更梦幻，但也更容易糊
- 调大（如 0.4）→ 干净利落

**粒子速度上限（`updateParticles`，约 470 行）**
```js
const MAXV = 13;
```
调大更狂野，调小更温柔。

**颜色主题（`spawnNebula` 约 316 行）**
```js
p.ci = hueIndex(rand(196, 300) + p.z * 26);
```
- `196–300` 是蓝→紫→粉的色相范围
- 想要青绿系：改成 `rand(150, 220)`
- 想要金色星系：`rand(30, 55)` 再把 `HUE_MIN`（263 行）改成 `0`

## 三、想加新功能，钩子在哪

**① 加一种新手势**
1. 在 `feed()` 里算出这个手势的数值，存到 `h.xxx`
2. 在 `updateHands()` 里把它平滑一下
3. 在 `updateParticles()` 的力场代码里用上它

例子：张开手掌时"手指全部伸直"已经算出来了，可以再加一个"两根手指比 V"——判断拇指和小指伸展、中间三指弯曲。

**② 加一层新的粒子**
复制 `P` 数组的写法，建一个 `P2`，在 `draw()` 里多画一段循环即可。
比如做"只在指尖冒出的火星"：不用维护大数组，每帧从 `h.pts[8/12/16/20]` 生成十几个短寿命粒子。

**③ 加音效**
`burst()` 里加一个 `AudioContext` 的白噪声 + 低通扫频，捏合爆发时就很带感。需要用户点过页面才能播放（浏览器策略）。

**④ 双手互动**
两只手的坐标都有（`hands[0]`、`hands[1]`）。可以在两手之间连一条电弧，或计算两手距离，靠得越近粒子越亮。

**⑤ 换/换识别模型**
`loadEngine()` 里改 `modelAssetPath`。MediaPipe 还有姿态识别（Pose）、人脸（Face）、全身 33 点的版本，接口几乎一样，换成全身就能做"整个人站在星空里"。

## 四、改完怎么生效

- 正在跑的那个黑窗口不用关
- 改完 `index.html`，回浏览器按 `Ctrl + F5` 强制刷新
- 如果改了识别模型相关的东西，刷新一次就够，模型有缓存

## 五、注意

浏览器对摄像头有硬性限制：**必须通过 `http://127.0.0.1:xxxx` 或 https 访问**。
所以永远用「双击启动.bat」进，别直接双击 index.html。
